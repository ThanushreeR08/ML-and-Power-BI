# ML-and-Power-BI

## Capstone 1: Hotel Booking Cancellation Prediction
- Goal: Predict if booking will cancel Yes/No
- Tech: Machine Learning - Random Forest, XGBoost, Python + Power BI Dashboard
- Data: 119,390 hotel bookings (hotel_bookings.csv)
- Accuracy: ~85%
- File: Hotel booking cancellation prediction.ipynb
- Dashboard: capstone 1 hotel bookings dashboard.pbix

## Tech Stack
